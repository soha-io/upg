# 03 — Improving Language Understanding by Generative Pre-Training (Radford et al., 2018)

**One line:** a decoder-only transformer trained on next-token prediction
learns representations that transfer with minimal task heads — the causal
counterpart to BERT, and the direct ancestor of our forecaster objective.

## The math

Autoregressive factorization of a sequence's likelihood:

$$p_\theta(x_{1:T}) = \prod_{t=1}^{T} p_\theta(x_t \mid x_{<t}),\qquad
\mathcal{L} = -\sum_t \log p_\theta(x_t \mid x_{<t}).$$

The model is $L$ blocks of *causally masked* attention (mask
$\alpha_{ts}=0,\ s>t$), so the whole sequence trains in parallel yet every
prediction uses only the past. Fine-tuning adds
$\mathcal{L}_{\text{task}} + \lambda\mathcal{L}_{\text{LM}}$ — keeping the
generative loss as a regularizer.

The statistical content: next-step prediction is *the* canonical objective
for learning a dynamical system. If data are generated by a Markov process
$x_{t+1} = f(x_t) + \varepsilon_t$, the minimizer of one-step log loss is the
true transition kernel; everything the model needs to know about $f$ is
forced into the weights by the objective.

## What it means for the UPG

- Our forecaster target is literally this loss with Gaussian heads:
  $-\log p(y_{t+1} \mid y_{1:t}, u_{1:t})$ with
  $p = \mathcal{N}(\mu_\theta(\cdot), \sigma_\theta^2(\cdot))$. The map
  $x_{t+1} = \tanh(\kappa(Bx_t+gu_t)+b+\varepsilon_t)$ *is* a Markov kernel,
  so one-step log loss is the correctly matched objective — and because we
  simulate the generator, we can measure the gap between the model's implied
  kernel and the true one exactly.
- The auxiliary-loss trick ($\lambda\mathcal{L}_{\text{LM}}$) transfers: when
  training the step-6 model to output $\rho(J)$ or regime labels, keeping the
  next-step prediction loss in the objective prevents the representation from
  collapsing onto the label shortcut.
- Decoder-only = filtering: predictions at $t$ use $y_{1:t}$ only. That is the
  clinically deployable direction (early warning must be causal in time).

## Verdict

Adopted as the forecaster's training objective (causal next-step NLL +
auxiliary dynamical heads). The paper's transfer-learning ambition
(pretrain large, adapt small) becomes relevant only at Phase 4 when real
multi-study EMA corpora exist.
