# Unified Person Graph (UPG) — Project Status

Article series deriving an eight-dimensional network model of psychological functioning ("Eight-Dimension" model). Each batch = one journal-style manuscript + reproducible graph data + figures.

## Key decisions

- **Format:** article series (one paper per batch), composed into the full model in Batches J–K.
- **Shared formalism:** signed, weighted graphs `G = (V, W)`; five axioms (connectivity, non-dismissibility, mediated/unmediated influence, self-loops, signed superposition); encapsulated subgraphs (communicate only via mother node).
- **Time-gated weights** (introduced in Batch C): `w_ij(t) = g_ij(t) · w̄_ij` — sensitive periods, age-rising stability; inherited by later strata.
- **Citations:** APA 7; asterisk (\*) marks sources found beyond the provided library.
- **Per-batch deliverables:** `manuscript_src/*.md` → final `.docx` (pandoc), `data/*_nodes.csv` + `*_edges.csv` (weights, signs, types, gates, provenance), `scripts/generate_figures.py`, `figures/*.png`.
- Weights are **consensus priors** (rated + sourced, not yet estimated); every batch states falsifiability, validation pathway, limitations.

Batch I specifics: **methodological keystone, derives no graph.** Critical review of computational & mathematical psychology (all 12 folder-04 sources + Oxford Bibliographies math-psych + generative-AI/LLM family) vs. traditional verbal theory, then the explicit **mathematical toolbox** the whole series presupposed. Reliability/validity dividend (§6.2) previews Batch J. **Gödel used precisely, not forced** (§6.3): expressive self-modeling system can't be both consistent and complete → model targets consistency + openness over completeness (also resolves the "trainable agent" axiom). Maps directly onto base-framework machinery (W, D, L, x_t, B, u_t, attractors, control) so Batch J is now lighter. 4 figures (formal-levels, worked spectral example, phase-portrait+bifurcation, toolbox→need mapping). Self-found asterisked refs: Fiedler 1973, von Luxburg 2007, Belkin & Niyogi 2003, Hopfield 1982, Borsboom 2017, Sutton & Barto 2018, Liu et al. 2011, Gu et al. 2015, Estes 1950, Bush & Mosteller 1951, Strang 2016, Gödel 1931.
